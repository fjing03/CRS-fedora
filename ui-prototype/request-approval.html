How to use this page

Review and manage replacement requests from lecturers in your program.

  • Sort — click any column header to sort ascending/descending
  • Search — type in the search box to filter by course, lecturer, or keywords
  • Filter — use the status dropdown or the week filter to narrow results
  • Hover headers — hover a column name to see what it means
  • Bulk action — tick checkboxes then approve/reject multiple requests at once
  • Quick action — use the approve/reject buttons on individual rows
  • Request age — colour indicates how long ago it was submitted: ● ≤1 day ● 2–3 days ● 4+ days
