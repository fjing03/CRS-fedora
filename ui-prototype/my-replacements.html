How to use this page

Every class that needs a replacement, and every request you have made for it — in one list.

  • Sort — click a sortable column header to sort ascending/descending; the arrow shows which one is active
  • Search — type to filter by course code, course name or cohort code
  • Hover headers — hover a column name to see what it means
  • Track progress — the Action icon tells you what you can do: rotate to arrange, ban to cancel a pending request, eye to view the details
  • Week filter — use the week navigator to view conflicts for a specific week
