How to use this page

Every class of your cohort that cannot run as timetabled — a cancellation or a public holiday — and how far its replacement has got.

  • Read-only — your Programme Leader arranges the replacement; this page only tells you where it stands
  • The week — the week selector narrows the list to one week; a row can name two different weeks, one for each slot
  • COMPLETED — the switch hides classes whose replacement date has already passed; turn it off to see them again
  • Status — Awaiting Arrangement (no request yet), Pending (waiting for a decision), Approved (attend the requested slot), Completed (that date has passed)
  • Details — click a row, or a card on a phone, for the full replacement details
